# Repository agent instructions

## Owner-approved execution and verification standard (2026-10-30)

Mandatory for all changes, agents, workflows, and operational reporting: read and follow [docs/EVIDENCE_FIRST_EXECUTION_STANDARD.md](docs/EVIDENCE_FIRST_EXECUTION_STANDARD.md). Report problems with options, preferred solution, immediate action, evidence-backed verification, and fallback. Do not mark unverified actions as completed. Preserve all existing project-specific safeguards. Document-only adoption is not proof of runtime enforcement; add tests and independent checks before claiming an app complies.
