# Blockley Farm Enterprises

Official static website for Blockley Farm Enterprises, Karoi, Zimbabwe.

The site is designed for deployment from this repository to Netlify. It includes farm service contacts, WhatsApp/call/email links, genuine farm photography and a responsive gallery.

## Hosting

Netlify can import this repository directly. No build command is required. Publish directory: repository root.

## Updating

Changes committed to the main branch can be redeployed automatically by Netlify.
